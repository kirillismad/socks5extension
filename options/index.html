    !

    Routing limits

    This changes Chrome's proxy settings for supported URL requests, including HTTP, HTTPS and FTP. It does not cover all browser traffic, device traffic, or separate UDP/WebRTC flows. DNS resolution through SOCKS5 depends on Chrome behavior and is not guaranteed.

    Chrome may use a direct connection after some proxy errors. The extension can show reported errors, but cannot guarantee fail-closed behavior. When disabled, it explicitly sets Chrome to direct connections instead of restoring a previous or system proxy. This does not bypass a system VPN or TUN tunnel.
