SOCKS5 Route Privacy Policy

Last updated: October 20, 2026

Scope

This policy covers the SOCKS5 Route Chrome extension. The extension configures a SOCKS5 server chosen by you. It does not provide a proxy server, VPN service, user account, or subscription.

Information Stored on Your Device

The extension uses chrome.storage.local to save your proxy server address and port, hostname exception patterns, proxy and routing preferences, and extension error state. This information is used to apply your configuration and display status. It is not sent to the extension developer or synchronized by the extension to a cloud account.

The extension does not record visited URLs or browsing history and does not include analytics, advertising, tracking cookies, or telemetry. Chrome evaluates hostname routing rules to choose a connection route; the extension does not keep a log of those requests.

Your Chosen Proxy Server

When you enable the proxy, supported requests assigned to SOCKS5 are sent through the server you configured. That server is not operated or supplied by this extension. Its operator may observe destination information, connection timing, and other network metadata. Content sent without end-to-end encryption may also be visible to the operator. SOCKS5 itself does not encrypt traffic; HTTPS provides its own transport encryption.

Hostname exceptions connect directly when Routing is enabled. When Routing is disabled while the proxy is enabled, the saved exceptions are not applied. Chrome may use a direct connection after some proxy errors. The extension does not guarantee anonymity, leak prevention, DNS routing through the proxy, or protection of all browser or device traffic. Review the privacy practices of your chosen server operator separately.

Permissions

  • proxy: reads and changes Chrome proxy settings, applies locally generated routing rules or direct mode, and receives proxy error notifications.
  • storage: saves configuration and error state locally.

The extension requests no host permissions or browsing-history permissions and injects no content scripts into websites. It downloads no remote executable code.

Import and Export

Export creates a JSON file containing the proxy URI and hostname exception list. Import reads a local file that you select and replaces those settings only after validation and your confirmation. These operations do not upload the file to a server. Exported files can reveal a proxy address or private hostname patterns; share and store them with care.

Retention and Removal

Saved settings remain in the extension's local storage until replaced or removed. Disabling the proxy or disabling the extension does not delete them. Chrome normally removes extension local storage when you uninstall the extension. Exported JSON files are separate files and must be deleted by you if no longer needed.

Turning the proxy off inside the popup explicitly selects Chrome direct mode. Disabling or uninstalling the extension instead releases its control over Chrome proxy settings, so system or other proxy settings may apply again. None of these actions disables an operating-system VPN or TUN tunnel.

Disclosure and Sale

The extension does not transmit locally stored configuration or browsing history to the developer, sell user data, or use user data for advertising. Routing traffic through your chosen SOCKS5 server is part of the requested functionality, not a developer-operated analytics service.

Changes and Contact

This policy may be updated when the extension's behavior changes. Updates will appear on this page with a revised date. For privacy questions, use the publisher contact email shown on the extension's Chrome Web Store listing.
